# The experience-layer dogfood

This report records the first run of the experience layer on its own project: the migration of `docs/requirements/` into `docs/experience/`, run inside the plan that builds the layer. It gives the measurements the run produced, read from one verification sweep over the tree as the last batch left it, from the recommendation and the direction that settled it, and from the conductor and implementer ledgers. Every figure names its source; a figure that could not be counted exactly is given as the part that could. It judges nothing.
